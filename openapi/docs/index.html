endDay
required
string or null <date>

終日予定の終了日（開始日以降。時間指定の予定ではnull）

startTime
required
string or null <date-time>

endTime
required
string or null <date-time>

時間指定の予定の終了日時（開始日時より後。終日予定ではnull）

isOnline
required
boolean

true：オンライン開催 / false：オフライン開催

required
boolean or null
